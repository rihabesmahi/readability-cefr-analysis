# Data

The raw corpus `.txt` files used in this analysis are **not included** in this repository.

They consist of excerpts from *English File* (Oxford University Press), a commercially published and copyrighted ELT textbook series. Redistributing this content publicly would infringe the publisher's copyright, even though its use for private, non-commercial academic analysis is standard research practice.

To reproduce this analysis:

1. Source 5 reading passages from the same (or a comparable) ELT series, one per CEFR level: A1, A2, B1, B2, C1
2. Save each as a plain `.txt` file, named `A1.txt`, `A2.txt`, `B1.txt`, `B2.txt`, `C1.txt`
3. Upload them when running `notebook/readability_analysis.ipynb`

For reference, the original corpus used in this study had the following approximate word counts: A1 (853), A2 (877), B1 (1091), B2 (791), C1 (862).
